# api_advanced

Python scripts that query the Reddit API.

- `0-subs.py`: returns the number of subscribers for a given subreddit, or 0 if it is invalid.
- `1-top_ten.py`: prints the titles of the first 10 hot posts for a given subreddit, or None if it is invalid.
- `2-recurse.py`: recursively returns a list of all hot post titles for a given subreddit, or None if it is invalid.
- `3-count.py`: recursively counts given keywords in all hot post titles of a subreddit and prints them sorted by count.
